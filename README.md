# Network Protocol Classification Using Machine Learning

## About the Project
This project uses Machine Learning to classify network protocols based on network traffic data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Algorithms Used
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest

## Project Steps
- Load the dataset.
- Clean and preprocess the data.
- Analyze network traffic.
- Train Machine Learning models.
- Test the models.
- Compare model accuracy.
- Predict network protocols.

## How to Run
1. Download the project.
2. Open the Jupyter Notebook in Google Colab.
3. Upload the required dataset.
4. Run all cells.

## Purpose
This project is developed for educational purposes.
